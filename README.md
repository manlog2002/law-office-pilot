# law-office-pilot
منصة تجريبية متكاملة لإدارة مكاتب المحاماة في المملكة العربية السعودية، صممت لتنظيم القضايا والمهام اليومية وتتبع مواعيد الجلسات ومستجدات منصة ناجز. يتيح النظام إدارة ملفات الموكلين بمرونة، وتوزيع أعباء العمل بين المحامين، مع نافذة ذكية لمتابعة استفسارات العملاء واقتراح الردود السريعة بدقة واحترافية عالية.
